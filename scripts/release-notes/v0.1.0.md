# SelfGit v0.1.0 — 初始发布

自研轻量 Android 端 Gitea 应用商店客户端（Kotlin + Jetpack Compose），面向个人开发者的私有 APK 分发与版本管理。

## 功能特性

- **混合登录**：账号密码引导创建双令牌（细粒度 + 全权限），运行期仅使用令牌；支持主/备地址自动切换与失效重认证
- **仓库浏览**：全量仓库列表、关键词搜索、置顶排序、追踪角标、图标三级回退（本机已装 → 远端 → 占位）
- **版本管理**：历史版本浏览、版本号比较、安装前签名 SHA-256 校验与降级检测
- **手机端上传**：SAF 选择 APK、解析包名/版本/ABI、tag 查重、自动建库（一应用一库 + apps 孤品档）、上传记录、上传可取消
- **安装四后端**：系统安装器 / Shizuku / Root (libsu) / 第三方（外部应用约定 app.json 可识别追踪）
- **UI**：玻璃拟态风格、Markdown 渲染、悬浮导航栏、明暗主题自适应

## 使用说明

1. 首次进入输入 Gitea 地址、用户名、密码（引导创建令牌，密码用完即弃不存储）
2. 主页浏览仓库，点进详情查看应用信息与历史版本
3. 「上传」页选择 APK 自动解析并上传到对应仓库
4. 安装方式可在设置中切换 Shizuku / Root / 系统
