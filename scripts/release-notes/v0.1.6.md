# SelfGit v0.1.6

在 v0.1.5 基础上优化文档阅读体验与细节交互。

## 修复与改进

- **Markdown 渲染增强**：
  - 修复粗体/斜体内嵌链接未渲染的问题（如引用块中「**⚠️ 需配合 [Gitea](…) 使用**」内的链接现已正确显示为可点击样式）
  - 新增 Markdown 表格渲染：表头底色、斑马纹行、圆角边框（README 中的环境要求、目录结构等表格正常显示）
  - 内联 HTML 降级处理：`<img alt="x">` → 显示 alt 文本，`<a href>` → 转为可点击链接，其余标签移除，常见 HTML 实体转义
- **登录页**：「创建令牌并登录」按钮改为占满卡片宽度，与「探测主机」一致
- **README** 新增界面预览截图
