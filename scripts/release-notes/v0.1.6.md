# SelfGit v0.1.6

在 v0.1.5 基础上优化文档阅读体验与细节交互。

## 修复与改进

- **App 内渲染 README 图片**：独立成行的 Markdown 图片与 `<img>` 标签现可在应用详情页实际加载显示（加载占位 / 失败降级 alt 文本）；相对路径自动走仓库 raw 端点（带令牌支持私库），会话级内存缓存
- **Markdown 渲染增强**：
  - 修复粗体/斜体内嵌链接未渲染的问题（如引用块中「**⚠️ 需配合 [Gitea](…) 使用**」内的链接现已正确显示为可点击样式）
  - 新增 Markdown 表格渲染：表头底色、斑马纹行、圆角边框（README 中的环境要求、目录结构等表格正常显示）
  - 内联 HTML 降级处理：`<img>` → 图片块，`<a href>` → 可点击链接，其余标签移除，常见 HTML 实体转义
- **登录页**：「创建令牌并登录」与「去 Gitea 网页端生成令牌」按钮均占满卡片宽度
- **README** 界面预览更新为两张拼图，并移除旧单张截图
