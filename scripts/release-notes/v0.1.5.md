# SelfGit v0.1.5 — 真机反馈修复

在 v0.1.0 基础上修复真机使用中暴露的问题，并改造地址配置逻辑。

## 修复与改进

- **本应用图标与安装角标**：图标回退链扩展 `logo.*`，仓库根目录补 `app.json` 约定文件，外部安装也能正确识别“已装/最新”
- **下载文件可见**：下载完成后同步复制到公共目录 `Download/SelfGit/`（同名覆盖），下载完成提示保存路径
- **第三方安装器枚举**：补充 `content://` scheme 探测与 `MATCH_ALL`，新增接管型安装器白名单（爱玩机等 LSPosed 安装接管模块不再需要注册 intent filter 即可列出，唤起时走系统安装器由其接管）
- **上传取得 APK 的两种新方式**：
  - 上传页「从已装应用选择」：搜索应用列表，提取其 base.apk 走统一解析上传链（Split APK 仅含基础包）
  - 系统分享：在其他应用分享 APK 时选择 SelfGit，自动跳转上传页并加载解析
- **主/备地址独立编辑**：设置页新增主地址编辑入口；保存前各自独立探测连通性，仅可达地址落盘，修复“只有备地址可达时主地址被备地址覆盖”的问题
- **权限与令牌**：rw 令牌补 `write:user` scope，修复新建仓库 403；MIUI「获取应用列表」未授权时给出引导提示
- **隐私**：输入框示例统一为通用占位（`192.168.x.x` / `gitea.example.com` / `your-username`），不含任何个人信息

## 升级说明

- 与 v0.1.0 同签名，可直接覆盖安装
- 若此前使用 debug 签名测试包，需先卸载再安装本版本

## 已知限制

- 第三方安装器接管模块（如爱玩机）仅在其已安装且启用时出现在列表
- Split APK 应用从已装应用提取时仅能上传基础包
