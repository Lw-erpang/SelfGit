## 1. 设计语言总则

1. **三层视觉结构**：底层极光渐变背景（含三色模糊光斑）→ 中层毛玻璃卡片（半透明面板 + 高光描边 + 柔投影）→ 顶层内容（三级文字色阶）。
2. **无涟漪点击**：全部可点区域禁用 Material 涟漪，按压反馈用轻微缩放 / 透明度变化表达，保留玻璃质感。
3. **弹性滚动**：列表两端带回弹，禁止生硬截停。
4. **悬浮导航**：底部悬浮胶囊导航，宽度内容自适应，随滚动方向显隐。
5. **克制的信息密度**：每屏一个主任务；卡片内二级信息用 tertiary 色 12~13sp；徽章独立成行（FlowRow 自动换行），不与标题争抢空间。
6. **经典窗口缩放处理输入法**：不启用 edge-to-edge 强制模式，键盘弹出由系统收缩窗口（详见第 8 章）。

## 3. 全局框架与导航结构

### 3.1 导航结构

底部悬浮胶囊导航，三个主目的地：

| Tab | 名称 | 内容 |
|---|---|---|
| 1 | 应用 | S1 仓库列表（首页，选中态展开显示文字） |
| 2 | 上传 | S3 上传页 |
| 3 | 设置 | S5 设置页 |

- 导航条为 Box 叠加结构（`align(BottomCenter)`），悬浮于内容之上。
- **滚动显隐**：snapshotFlow 监听滚动，累计 ±22px 触发——下滑隐藏、上滑 / 回顶显示；切换 Tab 或进出二级页自动复位显示。
- **自适应宽度**：导航条宽度由内容撑开（选中项 76dp 展开、未选中 46dp，总宽约 182dp），切换 Tab 时整条栏不做全宽伸缩。
- 二级页面（仓库详情、重新认证）从列表推入，顶部固定页头返回，不占用底部导航。
- 未登录时整个应用壳替换为登录页（S4）。

### 3.2 页面骨架

- **一级页**：固定页头（大标题 + 标题行右侧插槽）→ 可滚动正文。
- **二级页**：固定页头（玻璃渐变 + 圆形返回键 + 标题/副标题 + 右侧徽章槽）→ 可滚动正文。
- 页面根布局带 `statusBarsPadding()` 与 `imePadding()`，避免状态栏重叠与键盘遮挡。

## 4. 页面规格

### S1 仓库列表（首页）

- **页头**：大标题「我的仓库」；标题行右侧放大镜图标——点击展开搜索框（AnimatedVisibility），收起时清空关键词。
- **仓库卡片**（玻璃卡，占满宽度）：
  - 左：仓库图标（48dp 圆角；来源见第 6 章图标回退）
  - 中：仓库名一行（maxLines=1 省略）+ FlowRow 徽章行（自动换行）：`置顶`、`私有`、追踪角标——「已是最新」（success 绿）/「有更新 vX.Y.Z」（accent 橙）
  - 右：图钉按钮（实心 = 已置顶 / 描边 = 未置顶），点击即时切换并重排（置顶排最前）
- **搜索**：按仓库名 / 全名 / 描述过滤。
- **三态**：
  - 加载：缓存立即渲染；首次无缓存显示空态提示
  - 空态：玻璃卡居中提示，引导检查主机连接
  - 错误：保留缓存展示，Toast 提示失败原因

### S2 仓库详情

固定页头下方为**均分两栏玻璃分段控件**：「应用详情」/「版本」。

**应用详情板块**：

- **应用卡**（单卡，分割线分两段）：
  - 上段：应用图标（48dp）+ 应用名 + FlowRow 徽章行——`已装 vX`（绿）+ 最新标识：已装 < 最新 → `最新 vX`（橙）；持平 → `最新`（绿）；未安装 → `最新 vX`（蓝）
  - 下段：仓库描述等元数据行
- **README 卡**：Markdown 渲染（无"README"标题字样，直接渲染内容）。

**版本板块**：

- **版本时间线**：Release 倒序，每条一张折叠卡：
  - 头行：tag 名 + 日期 + 展开箭头（180° 旋转动画）；默认仅展开最新一条，附件行常驻可见
  - 展开区：修改日志 Markdown 渲染 + 元数据（包名 / versionCode / 架构）
  - 附件行：文件名 + 大小 + 「下载 / 重新下载」按钮；下载中显示百分比进度；失败自动清理半成品并显示重试
- **安装前提示弹窗**：下载完成后解析 APK，与本机已装版本比对——签名 SHA-256 不一致或降级安装时弹出警示（仍要安装 / 取消）。
- **图标回退链**（应用卡图标）：本机已装（追踪映射 → app.json 包名 → PackageManager）→ 远端（仓库 avatar → 根目录 `icon.png / jpg / jpeg / webp`，异步加载并落盘缓存）→ 占位图标。

### S3 上传

单页渐进展开，非弹窗式向导：

1. **选择文件卡**：两个入口按钮——
   - 「选择 APK 文件」（主按钮，占满宽度）：SAF 文件选择器
   - 「从已装应用选择」（次按钮）：打开**已装应用选择弹窗**——列表行 = 应用图标 + 应用名 + 包名 + 版本徽章；顶部紧凑搜索框（放大镜，按名称或包名过滤）+「含系统应用」选择 chip +「共 N 个」计数；选中后提取该应用 base.apk 走统一解析链（Split APK 应用提示仅含基础包）；列表为空时显示引导（部分系统需手动授予「获取应用列表」权限）
2. **解析结果卡**：应用图标 + 应用名 + 包名 + 版本徽章（versionName / versionCode）+ 大小 + 架构；解析失败卡转 danger + 重新选择。
3. **归属卡**：
   - 模式分段控件：`新建仓库`（默认，一应用一库）/ `已有仓库`
   - 新建模式：仓库名由应用名清洗推导（非法字符替换为 `-`，空则取包名末段），可编辑；创建失败（409 已存在）提示改名或改模式
   - 已有模式：仓库选择器，默认按包名匹配追踪映射自动选中
4. **发布信息卡**：tag 输入（模板 `{应用名}-v{版本}` 预填，可编辑）+ 700ms 防抖自动查重（冲突红字提示并禁用上传）+ 修改日志多行输入（模板预填）+ 固定元数据行（包名 / versionCode / 架构）
5. **执行区**：`上传` / `取消` 双按钮各占一半宽度——
   - 上传中：按钮区显示百分比进度；**取消 = 中断网络请求**（不写失败记录）
   - 空闲取消：清空整个表单
   - 失败（附件重试耗尽）：弹清理对话框——删除空 Release（默认）/ 保留待手动补传
6. **上传记录卡**（页底）：最近 10 条，行 = 状态点 + 应用名 + `tag → 仓库` + 时间 + 大小（失败附原因），右上清空按钮；无记录时整卡隐藏。本地留存最近 30 条。

### S4 登录与主机

- **登录页**（首次启动 / 重新认证）：
  - 主地址 + 备地址独立输入（备地址可留空）
  - 认证方式分段控件：`密码引导` / `粘贴令牌`
  - 密码引导：账号 + 密码输入；说明行「密码仅用于创建令牌，不会被保存」；成功后自动创建只读 + 读写双令牌（重名自动加后缀）
  - 探测：主 / 备地址**各自独立探测**，结果行分别显示「主地址可达 / 不可达」「备地址可达 / 不可达 / 未填写」，并说明保存规则
  - 探测通过（任一地址可达）才允许进入登录流程；**保存配置时只写探测通过的地址，绝不把可达地址回填为另一地址**
- **重新认证页**（401 触发）：同登录表单，顶部提供「返回设置」次按钮，系统返回键等效；取消后保留原凭据。
- **地址编辑弹窗**（设置页入口）：编辑主地址 / 编辑备用地址各自独立入口；保存前自动探测该地址连通性，仅可达地址落盘；备地址留空 = 清除；任一地址的保存不影响另一个。

### S5 设置

分组玻璃卡：

1. **主机**：显示名、主地址、备地址、账号、令牌名与创建时间；按钮行——`编辑主地址` / `编辑备用地址` / `重新认证`
2. **安装方式**：四选一 chip（系统 / Shizuku / Root / 第三方安装器），点击即时生效；下方状态行显示所选后端就绪情况（Shizuku 运行与授权、Root su 检测、第三方已装检测）
3. **第三方安装器选择弹窗**：三类探测（安装 action、APK mime、content:// scheme）合并去重 + 接管型安装器白名单；空态给出说明
4. **主题**：浅色 / 深色 / 跟随系统
5. **清除全部数据**：按钮占满宽度；弹窗二次确认，须输入「确认清除」才启用清除按钮
6. **关于**：版本号（读自 BuildConfig）

所有弹窗使用强玻璃底对话框（见第 5 章 GlassAlertDialog），内部带 `imePadding()` 兜底。

## 6. Markdown 渲染规范

`MarkdownText` 为零依赖自研实现，当前支持：

- 标题（1~6 级）、无序 / 有序列表（含任务项）、代码块、引用、分割线
- **粗体**、*斜体*、~~删除线~~、`行内代码`
- 链接（LinkAnnotation 可点击）
- 图片语法 `![alt](url)` 降级为 alt 文本渲染（不加载图片，避免仓库徽章图残留符号）

## 7. 状态与反馈规范

| 维度 | 规范 |
|---|---|
| 点击反馈 | 无涟漪；按压缩放 0.97 + alpha 0.9，spring 回弹 |
| 列表滚动 | ElasticScroll 两端回弹 |
| 加载 | 缓存优先秒开；刷新在后台进行，不阻塞浏览 |
| 空态 | 玻璃卡居中：一句话说明 + 行动引导 |
| 错误 | 就地提示（卡片转 danger / Toast）；下载失败自动清理半成品并提供重试 |
| 成功 | 上传成功显示 success 卡并触发全局刷新 |
| 危险操作 | 清除数据等用 GlassAlertDialog 二次确认，危险操作需输入确认文字 |
| 安装结果 | Toast 反馈（回退原因 / 静默成功 / 失败点） |

## 8. 输入法与系统栏适配

- **不启用 edge-to-edge**：部分输入法（如第三方中文输入法）在 edge-to-edge 下不上报 IME insets，导致 `imePadding()` 失效、输入框被遮挡。
- 当前方案：`MainActivity` 不调用 `enableEdgeToEdge()`，Manifest 声明 `android:windowOptOutEdgeToEdgeEnforcement="true"`（退出 targetSdk 36 的强制 e2e），保留 `windowSoftInputMode="adjustResize"`——键盘弹出由系统直接收缩窗口，不依赖 insets 上报，任意输入法有效。
- `statusBarsPadding` / `imePadding` 在该模式下自动归零，无回归；弹窗内部额外保留 `imePadding()` 兜底。

## 9. 深色模式

- 跟随系统，设置中可固定浅色 / 深色。
- 第 2.2 节深色色板为完整映射，逐令牌对应替换，不做局部混用。
- 深色下投影降至 12dp，blob 光斑透明度相应降低。
- 深色验收：所有玻璃卡在 `#060B14`~`#070D18` 渐变背景上有可辨识边界；三级文字对比度达标。

- 上传速度显示、仅 WiFi 下载开关、语言切换
